# Fenland Plastering Services — website

A responsive, static HTML/CSS/JavaScript homepage for GitHub Pages.

## Publish with GitHub Pages

1. Open the repository: https://github.com/fenlandplastering/fenlandplastering-redesign
2. Choose **Add file → Upload files** and upload the contents of this folder (not the enclosing folder).
3. Commit the files to the `main` branch.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/ (root)`, then Save.
7. Wait for GitHub Pages to publish, then visit https://fenlandplastering.github.io/fenlandplastering-redesign/.

## Before the site goes live

- Replace the phone and email placeholders in `index.html`.
- Confirm the exact services offered and remove any that do not apply.
- Add the actual service area once confirmed.
- Replace the designed photo placeholders with genuine project photographs in `index.html` / `style.css`.
- Check every statement and FAQ answer for accuracy.
- Add a working enquiry form if desired. The current page provides phone and email contact links only.

## Files

- `index.html` — page content and structure
- `style.css` — layout, responsive styling and colour palette
- `script.js` — mobile navigation and footer year
- `assets/logo.svg` — scalable architectural logo mark
- `assets/images/` — place project photography here
